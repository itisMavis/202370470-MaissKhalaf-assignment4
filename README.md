# 202370470-MaissKhalaf-assignment4

## Project Description
A fully developed personal portfolio web application showcasing academic, professional, and technical experience. The website includes structured sections for About, Education, Experience, Projects, GitHub repositories, Achievements, and Contact. It is built using HTML, CSS, and JavaScript with a clean, modern design and enhanced interactivity, presenting a polished and professional final product.

## Technologies Used
- HTML  
- CSS  
- JavaScript  

## Features
- Responsive layout (desktop, tablet, mobile)
- Personalized greeting that updates based on user input and time of day
- Professional Education and Experience sections integrated into a timeline-style layout
- Downloadable resume button in the hero section
- GitHub API integration to dynamically display repositories
- Project filtering and sorting functionality
- Dark/light mode toggle with saved user preference (localStorage)
- Animated highlight cards and scroll-based reveal effects
- Back-to-top button for improved navigation
- Clean, minimal styling with subtle hover effects
- Fully functional contact form using Formspree integration
- Real-time user feedback with success and error messages

## How to Use
- Type your name in the greeting input to see a personalized message.
- Click **Download Resume** to save a PDF copy of the resume.
- Browse GitHub repositories dynamically and sort them as needed.
- Use project filters to display specific categories.
- Toggle between dark and light mode; your preference will be saved.
- Scroll through sections with smooth animations and interactive elements.
- Use the back-to-top button to quickly return to the top of the page.
- Submit the contact form with valid input to send a message. Invalid or empty fields will display an error prompt.
