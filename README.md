# 202370470-MaissKhalaf-assignment3

## Project Description
A responsive personal portfolio featuring an About section, Projects, Achievements, and a Contact form. The site uses HTML, CSS, and JavaScript with a modern design, including a personalized greeting, API-powered content, and enhanced interactive features such as project filtering, sorting, and theme control.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
1. Responsive layout (desktop, tablet, mobile)
2. Personalized greeting that updates based on user input and time of day
3. API-powered insight section (Advice Slip API) with loading and error states
4. GitHub API integration to dynamically display repositories
5. Project filtering and sorting functionality
6. Dark/light mode toggle with saved user preference (localStorage)
7. Clean, minimal styling with subtle hover effects
8. Organized project showcase and contact form
9. Contact form validation with confirmation and error messages

## How to Use
- Type your name in the greeting input to see a personalized message.
- Click **Load Tip** to show a new short insight from the API.
- View dynamically loaded GitHub repositories and sort them as needed.
- Use the project filters to display specific categories.
- Toggle between dark and light mode; your preference will be saved.
- Submit the contact form with a valid email to see a confirmation message. Invalid or empty fields show an error prompt.
