# 202370470-MaissKhalaf-assignment4

## Project Description
A responsive personal portfolio featuring polished academic and professional content, including About, Education, Experience, Projects, GitHub repositories, Achievements, and Contact sections. The site uses HTML, CSS, and JavaScript with a modern design, including a personalized greeting, animated highlight cards, project filtering, repository sorting, and theme control.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
1. Responsive layout (desktop, tablet, mobile)
2. Personalized greeting that updates based on user input and time of day
3. Education and Experience sections integrated into the existing portfolio style
4. Downloadable resume button in the hero section
5. GitHub API integration to dynamically display repositories
6. Project filtering and sorting functionality
7. Dark/light mode toggle with saved user preference (localStorage)
8. Animated professional snapshot cards in the hero section
9. Clean, minimal styling with subtle hover effects
10. Contact form validation with confirmation and error messages

## How to Use
- Type your name in the greeting input to see a personalized message.
- Use the **Download Resume** button to save a PDF copy of the resume.
- View dynamically loaded GitHub repositories and sort them as needed.
- Use the project filters to display specific categories.
- Toggle between dark and light mode; your preference will be saved.
- Submit the contact form with a valid email to see a confirmation message. Invalid or empty fields show an error prompt.
