# AI Usage Report

## Tools Used & Use Cases

I used ChatGPT (Codex) to assist in planning and implementing the advanced features introduced in this assignment. This included guidance for integrating the GitHub API to dynamically fetch and display repository data, as well as refining the structure of the final portfolio sections.

The tool also helped structure JavaScript logic for handling user interactions, including filtering and sorting project content, animating the professional snapshot cards, updating the UI dynamically, and managing application state such as the dark/light mode preference using localStorage.

Additionally, AI provided support for implementing asynchronous JavaScript using `fetch` and `async/await`, including handling loading states and displaying user-friendly error messages for repository loading. It also assisted in refining the layout, improving small UI details such as hover effects, and organizing the documentation to maintain a clear and professional structure.

Overall, AI was used as a supporting tool to enhance interactivity, improve functionality, and guide problem-solving while ensuring the final implementation remained my own.

## Benefits & Challenges

Using AI helped accelerate the development process by providing quick solutions for implementing more complex features such as API integration, animated UI behavior, and state management. It made it easier to understand how to structure logic for filtering, sorting, and handling dynamic content updates.

One challenge I faced was ensuring that all features worked reliably, especially when dealing with asynchronous API requests, handling possible errors, and keeping interactive effects simple enough for the assignment. I also needed to simplify some AI-generated suggestions to keep the design consistent and aligned with the assignment requirements.

## Learning Outcomes

Through this assignment, I learned how to work with external APIs using `fetch` and `async/await`, including handling loading and error states.

I also developed a better understanding of implementing more advanced JavaScript logic, such as filtering and sorting data, managing application state using localStorage, animating content based on viewport visibility, and updating the interface dynamically based on user interaction.

Additionally, I improved my ability to design interactive web applications while maintaining clean and organized code.

## Responsible Use & Modifications

I carefully reviewed all AI-generated suggestions before applying them to my project. After implementing the suggested features, I tested them in the browser and made adjustments to ensure they functioned correctly and aligned with my intended design.

I ensured that the final implementation reflected my own understanding by modifying the logic, refining the structure, and simplifying features where necessary. This helped maintain originality while still benefiting from AI-assisted guidance.
