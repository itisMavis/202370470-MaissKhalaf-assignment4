# AI Usage Report

## Tools Used & Use Cases

I used ChatGPT (Codex) to assist in planning and implementing the advanced features introduced in this assignment. This included guidance for integrating the GitHub API to dynamically fetch and display repository data, as well as refining the structure of the final portfolio sections such as Education, Experience, and the overall page layout.

The tool also helped structure JavaScript logic for handling user interactions, including filtering and sorting project content, implementing scroll-based reveal animations, updating the UI dynamically, and managing application state such as the dark/light mode preference using localStorage.

Additionally, AI provided support for implementing asynchronous JavaScript using `fetch` and `async/await`, including handling loading states and displaying user-friendly error messages for repository loading. It also assisted in integrating a working contact form using Formspree, as well as refining layout details, hover effects, and overall visual consistency.

Overall, AI was used as a supporting tool to enhance interactivity, improve functionality, and guide problem-solving while ensuring the final implementation remained my own.

## Benefits & Challenges

Using AI helped accelerate the development process by providing quick solutions for implementing more advanced features such as API integration, animation effects, and state management. It made it easier to understand how to structure logic for filtering, sorting, and handling dynamic content updates.

One challenge I faced was ensuring that all features worked reliably, especially when dealing with asynchronous API requests, form submission handling, and ensuring animations remained smooth and not distracting. I also needed to simplify some AI-generated suggestions to maintain a consistent and professional design aligned with the assignment requirements.

## Learning Outcomes

Through this assignment, I learned how to work with external APIs using `fetch` and `async/await`, including handling loading and error states.

I also developed a stronger understanding of implementing more advanced JavaScript logic, such as filtering and sorting data, managing application state using localStorage, and triggering animations based on user interaction and scroll position.

Additionally, I gained experience integrating external services such as Formspree to create a functional contact form, and improved my ability to design interactive web applications while maintaining clean and organized code.

## Responsible Use & Modifications

I carefully reviewed all AI-generated suggestions before applying them to my project. After implementing the suggested features, I tested them in the browser and made adjustments to ensure they functioned correctly and aligned with my intended design.

I ensured that the final implementation reflected my own understanding by modifying the logic, refining the structure, simplifying features where necessary, and validating that all components met the assignment requirements. This helped maintain originality while still benefiting from AI-assisted guidance.
