# AI Usage Report

## Tools Used & Use Cases

I used ChatGPT (Codex) to assist in planning and implementing the advanced features introduced in this assignment. This included guidance for integrating external APIs such as the Advice Slip API and the GitHub API to dynamically fetch and display data.

The tool also helped structure JavaScript logic for handling user interactions, including filtering and sorting project content, updating the UI dynamically, and managing application state such as the dark/light mode preference using localStorage.

Additionally, AI provided support for implementing asynchronous JavaScript using fetch and async/await, including handling loading states and displaying user-friendly error messages. It also assisted in refining the layout, improving small UI details such as hover effects, and organizing the documentation to maintain a clear and professional structure.

Overall, AI was used as a supporting tool to enhance interactivity, improve functionality, and guide problem-solving while ensuring the final implementation remained my own.

## Benefits & Challenges

Using AI helped accelerate the development process by providing quick solutions for implementing more complex features such as API integration and state management. It made it easier to understand how to structure logic for filtering, sorting, and handling dynamic content updates.

One challenge I faced was ensuring that all features worked reliably, especially when dealing with asynchronous API requests and handling possible errors. I also needed to simplify some AI-generated suggestions to keep the design consistent and aligned with the assignment requirements.

## Learning Outcomes

Through this assignment, I learned how to work with external APIs using fetch and async/await, including handling loading and error states.

I also developed a better understanding of implementing more advanced JavaScript logic, such as filtering and sorting data, managing application state using localStorage, and updating the interface dynamically based on user interaction.

Additionally, I improved my ability to design interactive web applications while maintaining clean and organized code.

## Responsible Use & Modifications

I carefully reviewed all AI-generated suggestions before applying them to my project. After implementing the suggested features, I tested them in the browser and made adjustments to ensure they functioned correctly and aligned with my intended design.

I ensured that the final implementation reflected my own understanding by modifying the logic, refining the structure, and simplifying features where necessary. This helped maintain originality while still benefiting from AI-assisted guidance.
